# Orbital Transfer Visualization and Fuel Optimization

## Objective
This mini project studies orbital transfers between circular orbits, with a focus on Hohmann transfer. The goal is to visualize transfer trajectories and analyze fuel cost using total delta-v as the main criterion.

## Scope
The first version of the project includes:
- visualization of initial orbit, target orbit, and transfer ellipse
- computation of delta-v for Hohmann transfer
- parameter sweep over different orbit radii
- plots showing how transfer cost changes with orbital configuration

## Possible Extensions
- bi-elliptic transfer
- time-vs-fuel tradeoff
- plane change maneuvers
- simple transfer strategy comparison

## Tools
- Python
- NumPy
- Matplotlib
- Git/GitHub

## Project Structure
- `src/`: core functions for orbital calculations and plotting
- `notebooks/`: experiments and analysis
- `figures/`: exported plots
